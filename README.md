A single original one-liner about running a marathon — the joke being that the finish line is never really the finish. One line, no fuss, just the punchline going the distance.

> I signed up for a marathon so I could finally finish something, but halfway through I realized the finish line was just another starting line with better snacks.

161 characters. How it works: main.py validates the line, writes it to entry.txt with no trailing newline, then reads it back and re-validates the exact bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
